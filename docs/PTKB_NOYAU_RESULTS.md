# PTKB 逐句 → 经验 noyau → 非可加性:实验结果(iKAT-23,2026-07-18)

> 设计见 PTKB_NOYAU_DESIGN.md(对齐 Mo et al. CIKM'24,增量 = 非可加性检验)。
> 管线:qwen3-32b-AWQ(vllm TP2,T=0)+ MQ4CS 极简 prompt;176 评测 turn;
> 检索 = BM25(pyserini 批量)+ qwen dense(单查询 instruct 模板,int8 库流式精确扫描);
> 指标 per-turn NDCG@3(官方 qrels);共 2,339 次改写、双腿各 ~2.3k 查询打分。

## 0. 确定性证明(噪声地板)
30 个 (turn,句) × 3 次重复:**BM25 侧 90/90 分数逐位相同(ε=0,全管线确定)**;
dense 侧 5/90 出现微差(打分侧批组成噪声,p95=0.011 → ε_dense=0.0113)。
Fengran(T=1)从原理上不可能有这个性质;我们的每个 Δ 均可归因于语句本身。

## 1. 逐句阶段
- **40% 的单句注入产生与 ∅ 逐字相同的改写**(722/1818)——模型自行判断无关,Δ 精确为 0;
- 经验 noyau 非空:BM25 **57/176**、dense **58/176**(Fengran 报 ~98/~89:他的 T=1 噪声
  把"需要 PTKB"的 turn 数抬高了近一倍——winner's curse 实锤);
- **与人工标注重叠极低**:句级重叠 BM25 6 条 / dense 15 条(自动 183/193 vs 人工 98)——
  "标注相关 ≠ 检索有用"复刻并强化,与 attention 分析 F3 互证。

## 2. 非可加性(头条,noyau≥2 句、句句单独正向的 turn)
| | BM25 (n=37) | dense (n=42) |
|---|---|---|
| **合并后由正转负(sign flip)** | **3 (8%)** | **2 (5%)** |
| 合并不如最好的单句 | 18 (49%) | 22 (52%) |
| 介于最优单句与单句和之间 | 15 (41%) | 18 (43%) |
| 超可加 | 1 (3%) | 0 |
| 均值:Δ合并 / max单句 / Σ单句 | +0.17 / +0.31 / +1.09 | +0.18 / +0.28 / +1.20 |

**结论**:"单独正向 ⇒ 叠加正向"**大体成立但严重打折**——
① 合并几乎总是正的(92–95%),彻底翻车罕见但真实存在且幅度可观
(最惨 dense 12-1-4:两句各自正向,合并 Δ=−0.39);
② **一半的 turn 上,合并所有正向句还不如只放最好的那一条**;
③ 平均而言合并只保住单句增益之和的 ~15%,甚至只有最优单句的 ~60%。
ε 敏感性(dense 用 ε=0.0113 重筛):数字不变,结论稳健。

## 3. 全局条件均值(176 turns)
| 条件 | BM25 | dense |
|---|---|---|
| ∅(无 PTKB 改写) | 0.1274 | 0.1911 |
| full(全量 PTKB 改写) | 0.1317 (+0.004) | 0.1940 (+0.003) |
| **oracle noyau** | **0.1854 (+0.058)** | **0.2546 (+0.064)** |

全量 PTKB ≈ 白给(和 W1 / Fengran 的 "Use all"≈None 一致);oracle 选择的上界收益 ~+0.06。

## 4. 对 report 的写法建议
- 叙事链:人工标注不可靠(重叠 6/183)→ 经验正向句存在但稀疏(1/3 的 turn)→
  即便句句正向,合并即打折、偶尔反噬 → 所以"塞更多画像"不是路,**选择与克制**才是;
  与 X1≥R4(线上抽取无增益)、attention F3(按区分度不按标注)三线互证。
- 必要声明:noyau 用 test qrels 选出 = oracle 分析;组合条件用严格 Δ>0 noyau 生成;
  dense 打分侧有 ~0.01 噪声(已作 ε 敏感性);单年(23)单改写器(qwen3-32b)。
- 数据/脚本:scratchpad noyau_*.jsonl、scores_*.json、select_noyau.py、analyze_additivity.py。

# 续:Dense-direct 剂量-响应实验(同日,零 LLM 成本)

> 动机:QR 侧结论是否因"改写器门控"而特殊?dense-direct(模板恒定、只变 profile 内容,
> "Not Applicable" 占位)对逐渐加入的 PTKB 如何反应?蒸馏顾虑用双编码器对照解决
> (base qwen3 = 无蒸馏血统;PCDR = graded 微调,监督源于 human-QR 派生 qrels)。
> 2170(∅/逐句/full)+1946(noyau/前缀)变体 × 2 编码器,纯编码+流式打分。

## 5. 单句 Δ 分布:微调把 profile 的"杠杆"调小了 3 倍
| 路线 | 零效应 | 正 | 负 | p5 | p95 |
|---|---|---|---|---|---|
| QR→BM25 | 80% | 10% | 10% | −0.190 | +0.214 |
| QR→dense | 78% | 11% | 11% | −0.249 | +0.222 |
| direct-base | 81% | 11% | 8% | −0.153 | +0.133 |
| **direct-PCDR** | **86%** | 8% | **7%** | **−0.035** | **+0.078** |

**PCDR 对单句扰动的敏感度只有其他路线的 ~1/3**(p5/p95 区间收窄 3 倍)——
graded 微调让模型对 profile 更"钝感"、更稳健,与 attention 分析"预算转向当前问题"互证。

## 6. Direct 侧非可加性:现象在无改写器的路线上依然成立
direct-base(n=25):sign-flip 0%,合并<最优单句 48%;
direct-PCDR(n=25):**sign-flip 12%**,合并<最优单句 36%;
均值 Δ合并 只有 Σ单句 的 ~15%。**非可加性不是改写器的伪影,是两条路线共有的**。

## 7. 剂量曲线(共同子集,best/worst 前缀均存在的 turn;n=38-47)
direct-PCDR:**best-first 在所有剂量都显著高于 ∅**(k=3 时 0.423 vs ∅ 0.339,+0.084),
但随继续加料侵蚀(k=8 → 0.378);worst-first 略低于 ∅(−0.01~−0.03);rand ≈ ∅(**无中毒**)。
direct-base:best-first 与 ∅ 几乎无差(+0.01 量级)——**"会用好语句"这个能力是微调给的**。

## 8. 四路线同框(176 turns,∅ / oracle-noyau / full)
| 路线 | ∅ | oracle-noyau | full |
|---|---|---|---|
| QR→BM25(qwen32b 改写) | .127 | .185 | .132 |
| QR→dense | .191 | **.255** | .194 |
| direct-base | .099 | .143 | .108 |
| **direct-PCDR** | .193 | .222 | **.207** |

**最终叙事(可直接进 report)**:
- 无 oracle 的现实设定下(full profile),**direct-PCDR(.207)≥ QR→dense(.194)**:
  graded 微调让"对话+全量画像直接编码"追平并略超弱改写器 QR 路线——W1 的
  "direct 不行"是 base/conv 编码器的锅,不是路线的锅;
- QR 的天花板更高但只在 oracle 选句下兑现(.255);实际部署没有 oracle;
- 两条路线都被非可加性支配:好语句不叠加、坏语句进来就摊薄;
- 微调的真实作用:①降低 profile 敏感度 3×(稳健);②学会利用好语句(base 不会);
  ③代价是指代重读弱化(attention 分析)。
- Caveats:oracle 分析;单年;前缀排序按 PCDR-Δ 定义(base 曲线为借用序);
  best/worst 曲线在非平凡子集(有非零 Δ 的 turn)上。
